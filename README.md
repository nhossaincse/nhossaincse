# Hi, I'm Nazmul 👋

I build cloud platforms and AI systems, and I pay close attention to what they cost to run. 

I've spent 12+ years in software, most of it leading .NET teams that design and ship microservices on Azure and AWS. These days most of my work is LLM and agentic systems: AWS Bedrock, the Model Context Protocol (MCP), and the unglamorous parts that make them reliable and affordable in production.

- **Public-sector platforms**: 24/7 monitoring for public transport facilities (263 monitored points) and data dashboards, delivered under OWASP practices and third-party security testing
- **AI at scale**: an AWS Bedrock email platform handling around 10,000 emails a day, and a 35% cut in a Bedrock-heavy account's cloud spend
- MSc, Trent University (4.00/4.00 CGPA) · PMP · AWS Solutions Architect
